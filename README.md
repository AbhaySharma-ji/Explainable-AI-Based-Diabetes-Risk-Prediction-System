# 🧠 Explainable AI-Based Diabetes Risk Prediction System

## 📌 Overview

This project is an **Explainable AI (XAI)** based system that predicts the risk of diabetes and provides clear, human-understandable explanations along with personalized health recommendations.
Unlike traditional machine learning models, this system not only predicts outcomes but also explains **why** the prediction was made and **how** the risk can be reduced.

---

## 🚀 Features

* 🔍 Diabetes Risk Prediction using Machine Learning
* 📊 SHAP-based Feature Importance Visualization
* 💡 Personalized Health Suggestions (Custom Logic)
* ⚡ Real-time Prediction using Streamlit
* 📈 Risk Probability Output
* 🧾 Simple and Interactive User Interface

---

## 🛠️ Technologies Used

* Python
* Streamlit
* Scikit-learn
* SHAP (Explainable AI)
* Pandas, NumPy
* Matplotlib

---

## 🧠 XAI Contribution (Key Highlight)

This project goes beyond traditional ML models by integrating Explainable AI:

* ✔ Explains **WHY** a prediction is made using SHAP values
* ✔ Provides **ACTIONABLE SUGGESTIONS** to reduce diabetes risk
* ✔ Implements a simple **counterfactual logic system**

### 🔥 Example:

> If glucose level is reduced from 150 → 110, the risk of diabetes decreases significantly.
